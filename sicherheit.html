Sicherheit

Deine Daten gehören nur dir – geschützt durch clientseitige Verschlüsselung.

Startseite Sicherheit

Clientseitige Verschlüsselung

Das Herzstück der monkkee-Sicherheit ist die clientseitige Verschlüsselung: Alle Daten werden direkt in deinem Browser verschlüsselt, bevor sie dein Gerät verlassen. Der Server von monkkee empfängt ausschließlich verschlüsselte Daten – er hat zu keinem Zeitpunkt Zugriff auf deine Inhalte im Klartext.

Einmalig unter Webanwendungen: Mit diesem Verschlüsselungskonzept setzt monkkee einen Standard, der unter webbasierten Tagebuchanwendungen einzigartig ist. Deine Daten im Klartext existieren ausschließlich auf deinem eigenen Gerät.

Was wird verschlüsselt?

monkkee verschlüsselt konsequent – nicht nur den Eintragstext, sondern alle inhaltsbezogenen Daten:

  • 📝 Einträge: Der vollständige Text jedes Tagebucheintrags wird verschlüsselt gespeichert.
  • 🖼️ Bilddaten: Auch in Einträge eingefügte Bilder werden vollständig verschlüsselt.
  • 🏷️ Tag-Namen: Selbst die Namen deiner Tags verlassen dein Gerät nur verschlüsselt.
  • 🔍 Suchbegriffe: Textsuchbegriffe verlassen den Client nicht im Klartext – die Suche findet lokal statt.

Daten auf dem Weg zum Server

Wenn dein Browser Daten an den monkkee-Server sendet – etwa beim Speichern eines Eintrags – geschieht das ausschließlich in verschlüsselter Form. Die Übertragung erfolgt zusätzlich über eine gesicherte HTTPS-Verbindung.

Selbst wenn jemand den Datenverkehr zwischen deinem Browser und dem Server abfangen würde, wären die übertragenen Daten nicht lesbar.

Suche ohne Datenweitergabe

Eine besondere Eigenschaft von monkkee ist die lokale Volltextsuche: Wenn du nach einem Begriff suchst, wird dieser Suchbegriff nicht an den Server übermittelt. Die Suche wird ausschließlich im Browser durchgeführt – auf den bereits entschlüsselten Daten in deiner aktuellen Sitzung.

Dein Suchverhalten ist damit vollständig privat – mehr dazu auf der Seite Privatsphäre.

Infrastruktur und Verfügbarkeit

monkkee betreibt eine leistungsfähige Performance-Infrastruktur für zuverlässigen Betrieb. Dein Tagebuch soll jederzeit erreichbar sein – unabhängig davon, wann und von wo du schreibst.

Die Kombination aus Verfügbarkeit und Datenschutz ist dabei kein Widerspruch, sondern ein grundlegendes Designziel von monkkee.
